# V'Laun Banks Instructional Design Portfolio

This is a static website designed to publish for free with GitHub Pages.

## Files
- `index.html` — main website
- `styles.css` — visual design and responsive layout
- `script.js` — project case-study popups
- `assets/VLaun_Banks_Resume.pdf` — résumé linked from the site

## Publish free with GitHub Pages
1. Create a free GitHub account at github.com.
2. Create a new PUBLIC repository named `portfolio` (or any name you prefer).
3. Upload every file/folder in this package to the repository.
4. Open the repository's **Settings**.
5. Select **Pages** in the left menu.
6. Under **Build and deployment**, choose **Deploy from a branch**.
7. Choose the `main` branch and `/ (root)` folder, then click **Save**.
8. GitHub will generate your free URL, usually:
   `https://YOUR-GITHUB-USERNAME.github.io/portfolio/`

## Before publishing
- Open `index.html` locally in a browser and review all wording.
- Confirm the Articulate Review link is appropriate to share publicly.
- Remove or replace any project content that contains confidential employer information.
- If desired, add your LinkedIn link to the Contact section.
- The résumé currently includes your phone number and email address. If you do not want your phone number publicly available, replace the résumé PDF with a public-facing version before publishing.

## Easy edits
Open `index.html` in any text editor. Search for the sentence or heading you want to change and replace it.
